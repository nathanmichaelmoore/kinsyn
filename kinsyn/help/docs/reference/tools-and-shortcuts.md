# Tools and shortcuts

## Canvas tools

| Tool | Key | Use |
|---|---|---|
| Select | V | Click to select. Drag a pose's dot to move it, and its arrow tip to rotate it. Drag curve points, zone corners and pivots. Drag empty space to pan. |
| Pose | P | Click to place a pose; press-drag to place and aim it. |
| Point | O | Click to place path points. |
| Body | B | Click the outline of the moving part, then finish. |
| Curve | C | Drag to sketch freehand, or click points, then finish. |
| Zone | Z | Outline where ground pivots may go (Ctrl on the last click: keep-out). |
| Pivot | G | Click to fix a ground pivot; drag to fix a slider axis. |
| Measure | M | Click two points: distance and angle. |

**Finishing a shape** (body, curve, zone): click the first point, right-click,
double-click, press **Enter**, or press **✓ Finish**. **Backspace** removes
the last point and **Esc** cancels.

## While placing

| Input | Effect |
|---|---|
| **S** | Snapping on / off |
| hold **Shift** | 15° angle steps |
| hold **Alt** | Place freely (no snapping) |
| type numbers | Exact coordinates, e.g. `120, 45`, `120, 45, 30`, `@20, -10` |
| **Esc** | Cancel / back to Select |

## General

| Key | Action |
|---|---|
| Space | Play / pause |
| F | Fit view to window |
| Delete | Delete the selected keyframe, curve, zone or pivot |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo (target edits) |
| Ctrl+R | Reset mechanism to its template |
| Ctrl+N / Ctrl+O / Ctrl+S | New / open / save project |
| Ctrl+L | Save mechanism to your library |
| Ctrl+= / Ctrl+- / Ctrl+0 | Larger / smaller / default text |
| Ctrl+, | Preferences |
| F1 | This help |

Scroll to zoom the canvas. Right-drag zooms along an axis. Drag empty
space (or middle-drag anywhere) to pan.
