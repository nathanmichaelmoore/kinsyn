# Welcome to kinsyn

kinsyn helps you **design linkages**: arrangements of bars, pins and sliders
that turn one motion (a motor turning, a handle swinging, a cylinder pushing)
into another motion you need.

You don't need to be a mechanisms expert. Every term the app uses has an
explanation here, and most of them also have a tooltip. Hover over a label
to see one.

## Where to start

1. **[Tour of the window](tutorials/01-tour.md)**: what each part of the
   screen is for (2 minutes).
2. **[Explore a template](tutorials/02-explore-a-template.md)**: load a
   ready-made mechanism, change its dimensions and read the analysis.
3. **[Define a motion](tutorials/03-define-a-motion.md)**: use the pose,
   body, curve and snapping tools to describe the motion you want.
